# Client Setup Scripts

To easily configure your IDE/Client to point to a Hosted (or Local) MCP Server:

```bash
python scripts/install_clients.py
```

This will automatically prompt you for your Server URL & token, then configure:
1. Antigravity (`mcp_config.json`)
2. Claude Desktop
3. Claude Code
4. Cursor (`mcp.json`)
5. Windsurf
6. VS Code Copilot
7. OpenCode

No copy-pasting JSON required!
